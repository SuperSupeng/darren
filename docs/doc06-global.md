## 4）Become a node（成为城市节点）

### 标题

**Become a node / 成为节点**

### 文案

如果你也在一个城市长期 build，并且愿意：

* 聚集本地 builder
* 共办活动
* 帮作品获得真实展示机会

我们可以一起把这个城市变成节点。

### 我希望你具备

* 有稳定的社区/圈层触达能力（哪怕很小也行）
* 有一个活动空间或资源（联合办公 / maker space / 学校）
* 愿意以“交付作品”为核心

---

## 5）Co-host（共办活动）

### 标题

**Co-host / 共办活动**

### 可共办的形式

* Workshop（2–3小时，做出可运行 demo）
* Buildathon（时间盒交付作品）
* Demo night（作品展示与连接）

### 你提供（任一即可）

* 场地
* 传播渠道/社群
* sponsor 资源
* 导师/评审

### 我提供

* 活动机制设计（作品导向）
* 流程与交付节奏
* 传播文案与招募节奏
* 连接全球 builder 网络

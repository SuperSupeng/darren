## 3）我们怎么玩（How we run）

### 标题

**How we run / 我们怎么玩**

* **Show your work**：展示进行中的作品，不用完美
* **Ship weekly**：每周交付一个小版本
* **Learn by making**：少上课，多做 demo
* **Real-world feedback**：能上台 demo 就上台 demo

## 4）活动形态（Events & Programs）

### 标题

**Events / 活动形态**

#### 4.1 Workshop（工作坊）

**一句话：**2–3 小时，围绕一个主题做出可运行 demo。
**适合：**新人 builder / 想快速上手的人。

#### 4.2 Buildathon（作品黑客松）

**一句话：**在时间盒里交付作品（demo first）。
**产出：**作品、舞台、连接与机会。

#### 4.3 Cohort（共学营 / 共创营）

**一句话：**一群人按节奏一起 build。
**偏好：**固定节奏、公开交付、互相 push。

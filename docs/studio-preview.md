## 全站体验

- 首页：用「你好，我是 Darren」介绍本人，说明开发者活动、产品 Workshop 和 AI 实践分享，提供项目与合作的直接入口。下方精选案例展示角色与结果。完整交互房间可以左右拖动绕看，点击「工作案例」「产品」「文章与手记」标签或对应物件进入内容面板；房间热点跟随镜头，区域按钮提供键盘入口，Escape 或导航可以回到全景。导航保留原金色圆环 logo，介绍下方的头像可打开「关于我」。
- 工作案例：精选案例、全部项目分类目录及完整案例档案，保留原职责、成果、公开资料和下一案例入口。
- 产品：首屏以大幅透视工作台进入内容，点击工作台可定位当前产品目录；产品截图呈现为有厚度、支架和桌面投影的显示器。保留全部产品、真实链接与状态，并通过可展开的档案呈现问题、反馈和下一步。
- 手记：最新文章与全部手记；文章采用纸张阅读布局和侧边目录，保留原 Markdown 渲染、代码块和分享入口。
- 合作与关于：合作档案、邮件询问、个人经历与照片均保留，统一到房间与纸张的视觉体系。
- 导航与页脚：全站地图、双语切换、联系入口、日光 / 暮色以及静态浏览设置统一使用。

暮色状态写入 `?light=evening` 并保留在跨页、语言切换及分享地址中。静态偏好保存在当前浏览器。直接打开 `?light=evening#notes` 可以进入暮色下的手记区域。正文语言切换沿用原有的语义章节定位，阅读位置不会因标题翻译而丢失。

手机中房间在浏览首页面板时保持在顶部；内页使用窄屏导航、单列内容和可独立横向滚动的代码块。禁用 JavaScript 时提供直接页面与语言链接，隐藏不可用的交互按钮，静态图片与正文仍可浏览。

## 实现与内容保护

`StudioSettings` 管理全站光线与静态偏好；`SpatialHeader`、`SpatialFooter` 和共用样式构成全站框架。原首页结构化数据、页面 metadata、项目数据、文章正文与联系逻辑继续使用。

3D 由 React Three Fiber 和 Three.js 实现，房间与家具为程序化模型，照片来自现有公开素材。首页保留正交的完整场景；集合、合作和关于页采用无框的大幅透视近景，并在进入可见区域后加载。桌面鼠标提供轻微视差；桌面与手机都能横向拖动相机，手机竖向手势继续滚动页面。左侧、正面、右侧三个按钮提供等价键盘操作。

文章、案例详情和下方紧凑入口默认使用静态图片，点击「探索 3D」才加载可交互的局部场景。照片档案、产品显示器、文章纸页与合作文件夹延续实体边缘和投影，长正文不倾斜。关于页将房间与相片合并到首屏。

场景复用几何体和材质，限制纹理尺寸，复用静态阴影；镜头停止后按需绘制，离屏或切到其他标签页时暂停。热点通过相机投影更新 CSS，不进行每帧 React 状态更新。场景初始化失败、超时或绘图上下文丢失时保留静态图片和普通内容入口；可重新开启 3D。

没有新增数据库、内容管理系统或外部模型服务。

## 验证与限制

项目完整检查为 `npm run check`：ESLint、TypeScript、28 项测试和生产构建。测试覆盖现有内容约束、文章章节锚点、URL 状态、相机取景与拖动手势边界。

2026-09-06 浏览器走查覆盖桌面 1440 × 1000 及手机视口 390 × 844 的代表性页面和路径：

- 首页房间加载、三个区域、全景返回与集合页往返。
- 案例、产品、手记、关于、合作和 404 的排版与内容链接。
- 中英文导航、手机菜单开关、日夜跨页与分享地址保持。
- 产品档案展开、合作章节定位、邮件询问链接内容。
- 文章目录、跨语言章节定位、手机代码块的内部水平滚动。
- 全局静态 / 3D 切换、绘图上下文丢失后的静态回退与恢复。
- 透视近景与三个角度按钮、文章侧栏按需进入 3D、房间物件定位对应内容目录。
- 桌面拖动与真实浏览器触屏事件：横拖改变角度、竖拖滚动、不误触链接；减少动态偏好关闭自动视差，明确拖动仍有效。
- 真正禁用 JavaScript 的手机视口：全站与语言导航可见、无效控制隐藏、工作案例链接可直接访问。

这仍是供本机评审的实验版本。触屏验证使用浏览器触摸事件，并非真实手机；尚未进行 Safari 或真实 iOS / Android 设备的性能、温度和耗电测试，自动画质分级也尚未实现。

当前 3100 预览使用已构建版本在独立后台进程中运行。修改代码后，需要重新构建并重启该本地预览进程才能看到变化；临时开发验证可使用另一个端口，避免覆盖正在评审的页面。

React Three Fiber 依赖的 Three.js Clock 在开发模式会出现上游弃用提示；没有修改第三方依赖来隐藏它。

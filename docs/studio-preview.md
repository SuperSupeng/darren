# 山边工作室：独立预览

这是一个可以交互的 3D 视觉原型，用来判断空间、内容入口和阅读方式是否适合个人网站。

- 实验工作目录：`/Users/super/Desktop/darren-studio-3d`。

## 打开预览

在实验目录使用 Node.js 24 和 npm：

```sh
npm ci
npm run dev:studio
```

中文地址：<http://127.0.0.1:3100/zh/studio>

英文地址：<http://127.0.0.1:3100/en/studio>

暮色预览：<http://127.0.0.1:3100/zh/studio?light=evening>

本地服务绑定 `127.0.0.1:3100`，只供当前电脑访问。若已经在运行，不需要重复启动。

## 可以体验什么

- 在全景中点击长桌、产品台、窗边桌或书架，镜头会靠近对应区域。
- 房间内三处文字入口跟随镜头定位，鼠标悬停或键盘聚焦时显示简介，并强调对应桌沿。
- 顶部可以切换「日光 / 暮色」；暮色会改变窗外山景、场景光照，并点亮台灯、屏幕和工作台灯带。
- 下方三个区域按钮提供等价入口，也支持键盘操作。
- 查看真实案例、运行中的产品和最新手记，打开已有详情页或项目网站。
- 内容区域支持 Escape 返回全景；语言切换保留当前区域和光线，详情页返回也会恢复。地址中的 `?light=evening#notes` 可以直接打开暮色手记。
- 手机阅读内容时，房间保留在顶部；切换区域会定位到完整的面板顶部，关闭按钮仍可见。
- 「静态浏览」保留对应日光或暮色的真实场景截图和内容入口；可以重新开启 3D。场景初始化失败或失去绘图上下文时也会使用静态模式。

## 实现范围

原型用 React Three Fiber 和 Three.js 实现单个 3D 场景，房间和家具采用程序化模型，照片来自现有公开素材。模型几何体与材质复用，纹理限制尺寸，静态阴影复用，镜头停止后按需绘制，离屏或切到其他标签页时暂停绘制。

热点坐标直接从当前相机投影写入 CSS 变量，不引入每帧 React 状态更新。光线切换时更新一次阴影；悬停强调材质复用并统一释放，避免反复悬停造成材质堆积。

正文仍由已有内容源提供。服务端仅向场景界面传入每组 3 条精简记录；没有新增数据库、内容管理系统或外部模型服务。

新增的 `SiteChrome` 只在工作室路由隐藏普通网站框架，其他路由继续呈现原有导航、滚动组件、页脚及内容间距。
